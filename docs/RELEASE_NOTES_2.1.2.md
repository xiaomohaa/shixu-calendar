# 时序日历 2.1.2

- 时区仅在“设置 → 日历偏好 → 统一时区”中管理，默认 UTC+8 北京时间，不再根据电脑系统时区决定默认值。日历视图、新建日程和提醒统一使用该设置。
- 移除日程编辑中的时区输入、候选列表和浮动时间说明；其他日历界面不再增加时区展示。
- 编辑已有日程时，开始与结束时间按统一时区显示，保存时转换回来源时区，保留实际时间、原始 TZID、重复系列与浮动时间类型。
- 日视图、周视图的非全天事件改为日历颜色填充的时间块，左侧保留色条，并铺满对应事件时长。选中后加深为日历颜色，文字按背景明暗选择可读颜色。
- 月视图继续使用既有的非全天短色条、全天胶囊和节假日星标，保留搜索动画、数量折叠、新建预览与全部日历同步功能。

已安装 Tauri 2.x 的用户，可在“设置 → 关于与更新”中检查更新，下载后选择“重启并安装”。也可下载 `Shixu-Setup-2.1.2-x64.exe` 覆盖安装，保留本地数据和账户设置。
