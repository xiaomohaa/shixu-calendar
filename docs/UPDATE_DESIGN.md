# 1.2.0 桌面生命周期与更新

用户确认启动检查、设置内手动检查、按需下载、进度、取消及显式重启安装；随后指定关闭窗口收纳、可选开机自启和 SF Pro / 苹方字体，并要求字体目录一并公开。

## 主进程

固定使用公开 GitHub 仓库 xiaomohaa/shixu-calendar，不接收渲染进程提供的更新源或执行路径。electron-updater 6.8.9 读取安装包生成的 app-update.yml；仅正式版、禁止降级、不自动下载、不在普通退出时安装。更新控制器保留可用版本、成功检查时间、下载进度、错误和已校验状态，下载 promise 成功后才开放安装。更新说明作为纯文本展示。安装前封锁新 IPC 写入、停止同步并等待现有调用结束，退出时关闭数据库。队列、缓存和凭据目录不变。

安装版可下载并就地升级；便携/解压版只检查并打开固定发布页面，避免覆盖正在运行的文件。开发模式不检查。启动 12 秒后与每 6 小时检查，用户可关闭检查。错误只显示在设置中，不弹模态打断。

## 桌面行为

持有 Tray 实例。默认关闭隐藏窗口，后台继续同步和提醒。托盘点击/菜单、通知和第二实例可唤起；右键退出和设置退出使用相同的安全退出流程。关闭到托盘可取消。自启默认不创建注册表项，仅用户勾选后调用 Electron 登录项 API；使用安装 EXE 的完整路径及 --hidden 参数，登录后隐藏到托盘。不在开发/便携/解压版设置自启。读取操作系统当前登录项状态，也提示系统启动禁用状态。

## 字体与入口

Vite 将用户提供的 SF Pro 和苹方正文、中等、加粗字形打入静态资源，字体加载不需要系统安装。原始素材目录按用户要求公开；权利单独说明。苹方转换文件名不对应内部字重，CSS 按内部信息映射。

本机“Electron”快捷方式指向 node_modules/electron/dist/electron.exe 且无参数，所以启动的是开发工具的默认页面；安装版自身 PE ProductName、FileDescription 和正式快捷方式均正确。只清理核实指向该开发入口的错误快捷方式，保留开发工具和用户数据。

## 发布与验证

先构建并验证，提交和推送标签后创建 GitHub draft release，上传安装包、便携包、blockmap、latest.yml、SHA256SUMS，再公开并设置 latest。发布脚本先核对版本、标签和 SHA512；无任何 GitHub 密钥进入客户端。

回归原有 DAV/ICS/持久化测试，增加更新状态测试、真实 Electron HTTP 更新下载/取消/校验测试、真实打包字体渲染和窗口收纳验证。隔离安装升级测试使用不同 appId、独立路径和数据，避免覆盖真实用户账户。1.1.0 没有更新器，需手动安装本版本一次。
