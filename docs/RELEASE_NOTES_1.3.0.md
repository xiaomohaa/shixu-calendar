# 时序日历 1.3.0

- 按 macOS 日历参考重做主界面：灰色侧栏、大号深色年月、简洁工具栏、完整网格；提高正文与辅助文字对比度。
- 月视图改为固定七列六行布局，缩放时不反复测量日程文字或读取缓存，避免错位和尺寸残留。
- 空间足够时显示浅色日历胶囊，缩小时自动改用彩色点。长标题在日格内截断，+N 可展开当天全部日程；胶囊、圆点和列表均可点击编辑。
- 保留日期居中、农历黄历、节假日和调休，跨月全天事件、跨日拖选与拖动调整时间继续可用。
- 周、日、列表视图在容器变化后合并更新尺寸；大幅缩放时自动收起侧栏，日历内部可滚动查看。
- 返回月视图直接挂载固定网格，避免在替换前仍触发旧布局的密集日程测量。
- 保留字体、托盘、自启、离线缓存与内置更新。本版本不加入天气。

已使用 321 个真实 DAV 日程、67%–200% 页面缩放和连续 48 次尺寸变化验证；完整测试边界见 docs/VALIDATION.md。

安装版 1.2.0 用户可在“设置 → 关于与更新”下载并安装；更早版本及便携/解压版可从本页手动获取安装包。Windows x64，应用尚未签名。
