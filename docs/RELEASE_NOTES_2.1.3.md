# 时序日历 2.1.3

- 按参考图重做日程编辑浮层：移除“编辑日程/新建日程”标题栏及内部横向分隔线，使用左侧日历色竖条、柔和玻璃圆角框和更紧凑的布局。
- 标题改为 14px，正文、标签与设置控件统一 12px。标题支持自动换行，不再使用过大的单行输入框。
- 全天、起止时间、重复、行程时间、提醒放进同一个圆角设置框；地点、所属日历和备注分别放置于下方。
- 日期与时间分开点击设置。日期弹出六周小月历，支持上/下月、今天、键盘方向键和独立关闭；时间使用独立时钟输入。
- 保留显式保存、取消与删除，改为底部轻量操作，不添加横线；小窗口可以滚动填写和保存。
- 行程时间可手动设置并保存为日历资源属性，重新打开可读取；不会改变日程本身的起止时刻，也不自动估算路线。
- 保留统一时区、原始事件时刻与重复规则、全天日期、新建实时预览、CalDAV 和 ICS 订阅行为。

已安装 Tauri 2.x 的用户，可在“设置 → 关于与更新”中检查更新，下载后选择“重启并安装”。也可下载 `Shixu-Setup-2.1.3-x64.exe` 覆盖安装，保留本地数据和账户设置。
