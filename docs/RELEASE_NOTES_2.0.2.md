# 时序日历 2.0.2

- 顶部改为统一背景的自定义窗口栏，四角圆角增大；保留原生拖动、最小化、最大化/还原与关闭到托盘。
- 缩小年月标题与侧栏字号。日期、视图切换和“今天”使用一致的 14px 字号，农历为 12px；调整窗口大小时保持字号不变。
- 日格农历位于左上角，阳历位于右上角。移除内置中国节假日及调休表和“休/班”标记，节假日完全由导入的 ICS 日历显示。
- 月历始终显示全部六行日期。空间变小时保留至少一行文字日程，额外日程使用“+N个”展开，不再转成圆点。
- 保留跨天连续胶囊和跨周续接，胶囊与网格线之间留 3px 间距。
- “设置 → 显示设置”新增“显示黄历”，即时生效并保存；关闭黄历不影响日格中的农历日期。
- 侧栏随窗口宽度自动展开或隐藏，移除左上角的展开和设置按钮；窄窗口移到左边缘可临时展开侧栏，设置入口仍在侧栏底部，也可使用 Ctrl+,。
- 侧栏采用细圆角滚动条，去除上下箭头和厚重轨道。

本机验证包含旧设置兼容、固定字号、最小窗口全部日期与一行文字胶囊、折叠展开、农历/阳历角落位置、黄历开关持久化、自动侧栏、新窗口控制、CalDAV 与 ICS 订阅回归。

本版本先在本机提供安装包，尚未公开发布。
