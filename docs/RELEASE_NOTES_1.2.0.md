# 时序日历 1.2.0

- 关闭窗口默认收纳到系统托盘，后台继续同步和提醒；点击图标恢复，右键或设置中彻底退出。
- 新增“启动与后台”，可选开机自启，登录后隐藏到托盘；默认关闭，可取消关闭到托盘。
- 新增“关于与更新”：GitHub 正式版本检查、更新说明、按需下载、进度、取消与重试、校验后重启安装。普通退出不会自动安装。
- 更新前停止同步并保存数据，账户、凭据、缓存、离线修改与设置保留。便携和解压版提供手动替换入口。
- 英文数字内置 San Francisco / SF Pro，中文内置苹方，字体随包加载，无需系统安装。按用户要求公开 fonts 素材目录，字体权利单独说明。
- 安装与启动说明明确使用“时序日历”快捷方式或“时序日历.exe”，开发工具 electron.exe 无参数启动会显示其默认页面。

**从 1.1.0 或更早版本升级：请手动安装本版一次，以后可在软件内检查更新。**

Windows 10/11 x64。安装版支持自动更新及自启；便携版的数据仍保存在 Windows 用户应用数据目录中。应用尚未签名。

安装包、便携包、更新元数据 latest.yml、差分 blockmap 与 SHA256 校验清单一起发布。
