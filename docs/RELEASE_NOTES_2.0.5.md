# 时序日历 2.0.5

- 年视图按参考图重做为四列三行的十二个月概览：月份标题标红，日期无网格，不铺开日程胶囊；淡化相邻月份日期，仅标红今天。
- 年历中的农历初一使用红色下划线，顶部显示农历年份与初一图例。全年日期在最小窗口内也完整显示；年份导航、今天、月份入口及日期双击新建均可使用。
- 侧栏按 iCloud 或服务器域名分组，去掉重复的日历名称标题、云图标和“只读”标签，每个日历只保留彩色勾选框和名称。
- 日/周/月/年采用一个整体胶囊，只为当前视图显示灰色选中背景；日程列表入口移到右侧工具区。
- 日程胶囊高度从 18px 降为 16px，文字保持 10px，跨天连续与跨周续接继续保留。
- 关闭“在左侧显示日程”后，侧栏相关横向分隔线一并隐藏。
- 新建日程时，在对应日期实时显示本地预览。空标题显示“新建日程”，输入后跟随标题，全天开关切换完整胶囊或短色条；修改日期、日历及跨天范围时同步更新预览。
- 草稿只在编辑时显示，取消或关闭后移除，点击保存才写入本地日历和同步队列。繁忙日期也优先保留一行草稿预览，编辑已有日程不会生成重复草稿。

已安装 Tauri 2.x 的用户，可在“设置 → 关于与更新”中检查更新，下载后选择“重启并安装”。也可下载 `Shixu-Setup-2.0.5-x64.exe` 覆盖安装，保留本地数据和账户设置。
