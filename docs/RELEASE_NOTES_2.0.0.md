# 时序日历 2.0.0

时序日历迁移到 Tauri 2，沿用现有日历界面与字体。Windows x64 安装包约 **29.21 MiB**，相对 1.3.0 的 Electron 安装包减小约 **78.5%**。

- 保留 CalDAV 账户发现、完整及增量同步、离线缓存与待同步队列、条件写入及冲突处理。
- 保留日程新建与编辑、重复日程、时区、月/周/日/列表视图、农历黄历及已收录年份的中国节假日。
- 接入原生托盘、关闭窗口后后台运行、自动同步、Windows 提醒、可选开机自启及设置备份/恢复。
- 新增 Tauri 更新检查、下载进度、取消及更新签名验证；下载与安装由用户决定。
- 应用、窗口、托盘、安装器及界面统一使用原有红色日历 logo。

## 安装与旧版迁移

下载本页的 `Shixu-Setup-2.0.0-x64.exe`，支持 Windows 10/11 x64，使用系统 WebView2 Runtime。安装目录文件约 42.29 MiB；共享 WebView2 Runtime 的占用不包含在该数值内。

从 Electron 1.3.0 升级时，先从托盘彻底退出旧版，再手动安装 2.0.0。旧版应用内更新协议与 Tauri 不同，本次跨框架升级使用手动安装。

2.0.0 使用独立的数据目录。首次启动会将旧版数据库复制到新目录，保留日程缓存、离线修改、冲突和同步令牌。旧库保留；凭据无法在当前 Windows 用户下解密时，编辑账户并重新输入密码或应用专用密码。

`.sig` 和 `latest.json` 用于 Tauri 更新，普通安装只需下载 EXE。`SHA256SUMS.txt` 用于核对安装包完整性。Tauri 更新签名已启用，Windows Authenticode 代码签名尚未配置。
