# 时序日历 2.1.0

- 统一液态玻璃视觉：主窗口、侧栏、顶部工具区、日历底层、按钮、搜索框、日程胶囊、编辑浮层及设置面板采用半透明、模糊、柔和高光与细边框，浅色和深色主题均适配。
- 重做设置界面：左侧按“日历、显示、应用”分组，使用紧凑导航列表；账户行、长链接、操作按钮、表单和更新信息统一排版，支持最小窗口内滚动操作。
- 移除月份标题下的时区文字。显示时区仍可在“日历偏好”中设置，日程的时间解释与同步行为保持原有规则。
- 过去的日程不再使用淡色或降低透明度，使用与其他日程相同的文字、颜色和图标。
- 月历阳历保持 12px，农历改为 10px，比阳历小 2px；浅色主题农历为黑色，深色主题保持清晰的浅色文字。
- 全天日程前显示圆形日历图标；节假日日历前显示圆圈内五角星。根据节假日日历名称或订阅来源识别，不仅凭普通日程标题判断。非全天日程继续使用短色条。
- 保留四列三行年视图、跨天连续胶囊、新建实时预览、静默启动、CalDAV 与 ICS 订阅功能。

已安装 Tauri 2.x 的用户，可在“设置 → 关于与更新”中检查更新，下载后选择“重启并安装”。也可下载 `Shixu-Setup-2.1.0-x64.exe` 覆盖安装，保留本地数据和账户设置。
