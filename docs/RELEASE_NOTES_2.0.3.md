# 时序日历 2.0.3

- 侧栏顶部与侧栏统一为灰色，移除窗口左上角的“时序日历”文字。
- 侧栏文字、日/周/月/年切换和“今天”统一为 10px；视图切换采用半透明玻璃效果。
- 新增完整年视图，保留独立的日程列表图标入口。
- 阳历和农历日期固定为 14px，缩小窗口时保持字号。月历仍完整显示六行日期，并保留文字日程和“+N个”展开。
- 淡化月历和其他日历视图的网格线。
- 全天日程使用完整胶囊，非全天日程改为左侧短竖条加标题，日程列表中不再显示时间；编辑详情仍可查看和修改起止时间。
- “设置 → 显示设置”新增“在左侧显示日程”开关，即时生效并保存。
- “设置 → 启动与后台”新增“静默启动”。启用后下次启动直接进入系统托盘，后台同步和提醒继续运行；点击托盘图标或再次启动应用可打开窗口。

已安装 Tauri 2.0.0、2.0.1 或 2.0.2 的用户，可在“设置 → 关于与更新”中检查更新，下载后选择“重启并安装”。也可下载 `Shixu-Setup-2.0.3-x64.exe` 覆盖安装，保留本地数据和账户设置。
