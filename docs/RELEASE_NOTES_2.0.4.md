# 时序日历 2.0.4

- 侧栏日历勾选框调整为 10px；关闭“在左侧显示日程”时，同时隐藏所选日期标题和日程数量。
- 阳历、农历日期固定为 12px；每月 1 日显示完整月日（如“10月1日”），其他日期显示“29日”。缩小窗口时保持字号。
- 日程和“+N个”调整为 10px。浅色主题日程使用黑色文字，额外日程数量使用更淡的灰色；深色主题保留可读的浅色文字。
- 移除底部日历数量、缓存提示、同步时间和侧栏底部状态信息。
- 设置入口移到侧栏右上角，迷你月历保留在侧栏最下面。
- 侧栏迷你月历仅标红今天，导航、双击新建和编辑其他日期不再产生红色日期标记。
- 缩小左上角加号、应用图标及工具图标；工具、导航与设置按钮统一为液态玻璃效果。
- 窗口四角恢复为较小的 8px 圆角，最大化时仍使用直角。
- 单击月历日期不再选中或改变底色。双击日期后，贴近日格弹出玻璃日程编辑浮层，靠近窗口边缘时自动避让，小窗口内可滚动填写。
- 双击新建默认采用所点击的日期和显示时区当前小时整点；结束时间按“日历偏好”中的默认时长计算。例如当前 10:35、默认时长 60 分钟时，新建为所点击日期 10:00–11:00。
- 保留日历选择、全天、重复、提醒、地点、备注及编辑删除功能，静默启动和托盘行为延续上一版。

已安装 Tauri 2.x 的用户，可在“设置 → 关于与更新”中检查更新，下载后选择“重启并安装”。也可下载 `Shixu-Setup-2.0.4-x64.exe` 覆盖安装，保留本地数据和账户设置。
