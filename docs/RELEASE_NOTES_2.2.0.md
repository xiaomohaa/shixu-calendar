# 时序日历 2.2.0

- 新增 macOS 风格的 Windows 右上角悬浮日程提醒，使用 Tauri WebviewWindow 实现，无边框、透明、置顶、不激活窗口，并提供滑入/滑出动画。
- 通知高度按标题、正文和按钮内容自动测量，短内容不留固定空白；长内容有高度上限，按各卡片真实高度堆叠。
- 按当前前台窗口所在显示器的可用工作区定位，考虑任务栏、负坐标和 DPI 缩放；同时最多显示三条，其他通知进入持久队列。
- 支持浅色、深色、跟随系统和主题实时变化；悬停暂停消失，移开后继续计时。
- 支持10分钟后稍后提醒和打开对应日程。稍后提醒写入同一 SQLite，应用重启后继续处理到期任务；日程改期后打开最新内容，已有未保存编辑时先确认。
- 设置 → 启动与后台 → 日程通知，可选择“系统通知”或“macOS 风格悬浮通知”，并提供测试通知按钮。旧设置默认保持系统通知。
- 沿用现有30秒提醒 tick、ICS Worker 事件计算、notifyReminder 与 claim_reminder 去重，保留托盘和后台同步，不引入 Electron。
- 主窗口与通知窗口关闭分别处理，关闭通知不会触发主窗口收纳或退出；通知窗口只允许操作自身提醒，不能访问日历 IPC。

验证包含 Rust 测试、TypeScript 类型检查、前端测试和实际 Windows 通知回归。当前硬件实测为单显示器、200% DPI；其他 DPI、负坐标、多工作区尺寸和可变高度堆叠由几何测试覆盖，未宣称完成多显示器插拔硬件验证。

已安装 Tauri 2.x 的用户，可在“设置 → 关于与更新”中检查更新，下载后选择“重启并安装”。也可下载 `Shixu-Setup-2.2.0-x64.exe` 覆盖安装，保留本地数据和账户设置。
