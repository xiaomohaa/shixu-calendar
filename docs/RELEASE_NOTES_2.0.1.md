# 时序日历 2.0.1

- 设置中新增独立的“显示设置”分区。
- 新增“启用粗体显示”开关，加粗日历、日程及设置文字，同时保留标题层级。
- 开关自动保存，修改后立即生效，下次启动保留；关闭后恢复原有字重。
- 兼容旧版偏好和设置备份，未设置过粗体的用户默认保持关闭。
- 窗口最小尺寸降至 480×360，月视图固定展示六行日期，缩小后无需滚动查看其他日期；空间不足的日程从当天数量入口展开。
- 跨天日程合并为连续胶囊，左右对齐起止日期网格线，跨周续接；重叠日程分行显示，全天日程保持结束日期不包含在内的规则。
- 胶囊高度调整为 18px，正文 11px、时间 9px；极小窗口下进一步压缩以保留全部日期。
- 已结束的日程淡化显示，以结束时刻判断；正在进行和未结束的全天日程保留原色，运行期间自动更新状态。
- 控件统一采用胶囊样式，搜索默认显示圆形放大镜按钮，点击展开胶囊搜索框。
- “设置 → 账户与同步”新增“通过 ICS 链接导入日历”，支持 iCloud 节假日等公开 ICS / webcal 链接。订阅日历为只读，支持手动/自动刷新、暂停和删除本地订阅。

已通过真实 Tauri WebView2 的开关操作、字体实际字重、重新载入后保留、关闭后恢复、最小窗口全部日期可见、胶囊网格边界/跨周续接/尺寸、结束淡化、圆形搜索及托盘生命周期验证。ICS 导入已验证只读限制、刷新和持久化；用户提供的真实 iCloud 中国节假日链接成功展开 2026 年 55 条节假日日程。

本版本目前仅在本机准备，按用户要求暂不发布 GitHub。
