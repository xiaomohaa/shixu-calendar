# 时序日历 2.2.1

- macOS 风格通知固定显示在主显示器的可用区域右上边缘；标题、正文与操作使用加粗字体。主显示器切换时重新定位，继续避让任务栏并适配 DPI。
- 日程编辑弹窗使用更通透的液态玻璃表面，缩小设置行距、分组留白和地点/日历输入高度。标题和备注随内容增高，删短后自动收回，短标题不再留大块空白。
- 普通日程删除确认明确显示“当前日程”，不再误称“整个日程系列”。重复日程删除默认“仅此日程”，还可选择“此日程及未来日程”或“整个重复系列”。
- 删除未来日程会保留之前的记录、UID、提醒和已发生的重复例外，并继续使用原有离线写入与 CalDAV 同步。复杂范围例外会明确提示在原服务处理，避免误删历史。

继续使用 Tauri 2 + Rust + React，保留系统通知、提醒去重、持久化稍后提醒和托盘后台运行。

验证包括 Rust 测试、TypeScript 类型检查、前端/ICS 测试、真实 Windows 通知与编辑器测试、CalDAV 删除往返同步，以及正式 Windows x64 安装包构建与更新签名验证。实际通知验证设备为单显示器200% DPI；其他 DPI 和负坐标由几何测试覆盖，真实多显示器切换仍需相应硬件验证。
