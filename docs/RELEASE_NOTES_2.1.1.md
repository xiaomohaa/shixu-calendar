# 时序日历 2.1.1

- 日格空间不足以显示两行时，同一天有两项日程会直接显示“+2个”，不再把一个胶囊和“+1个”叠在同一行。更多日程也为数量入口单独保留一行，可点击查看全部。
- 跨天胶囊经过需要折叠的日期时自动分段，避免遮挡数量入口；新建时仍优先显示实时草稿预览。
- 搜索改为顶部原位展开：点击放大镜向左展开输入框，放大镜和左侧日程列表图标随动画移动，不再在下方增加搜索行。支持 Ctrl+F、Escape 和关闭后清空查询；窄窗口中展开时临时收起视图切换以避免拥挤。
- 压紧工具栏、年月标题和星期行之间的留白。月份标题与日期字号保持不变，日历获得更多垂直空间。
- 上一周期、今天、下一周期改为更紧凑的 22px 轻量按钮，保留液态玻璃整体风格。
- 保留全日期显示、年视图、实时新建、全天图标、节假日星标、设置、静默启动与日历同步功能。

已安装 Tauri 2.x 的用户，可在“设置 → 关于与更新”中检查更新，下载后选择“重启并安装”。也可下载 `Shixu-Setup-2.1.1-x64.exe` 覆盖安装，保留本地数据和账户设置。
