# 时序日历实施设计

运行环境：Windows 10/11 x64。主进程唯一持有网络、SQLite 和 DPAPI 加密凭据；渲染进程通过受限 IPC 调用服务。所有输入在主进程使用 Zod 校验。

协议方案：评估 tsdav 的发现、REPORT 与条件写入 API，复用它的 DAV/XML 和认证能力，同时补充受控请求、同源认证重定向和直接日历地址回退。同步保存完整 ICS，不重建未知属性。每个账户串行同步，数据库事务提交拉取结果；离线变更以资源为单位合并持久化，使用 If-Match / If-None-Match，412 时保存双方版本。有效 sync-token 优先，服务器不支持或令牌失效则全量 REPORT。

数据库方案：使用 Electron 所携 Node 的 SQLite，不需要本机编译器。迁移采用 user_version 与事务。数据包括账户、日历、资源、同步状态、待提交队列、冲突和设置。账户删除只删除本地关联数据；清缓存保护未提交变更。

界面方案：240px 侧栏、顶部日期导航与分段视图选择、FullCalendar 月/周/日/列表，右侧日程编辑器。首次启动无示例数据，显式引导添加账户。使用系统中文字体、暖灰面板、朱红强调色，事件颜色由日历决定，支持系统/浅色/深色。无需位图素材，图标采用 Lucide。

阶段：初始化与本地持久化；安全 IPC 和真实发现；同步与 ICS 编辑；完整 UI 和设置；模拟 DAV 集成测试；安装包与实际 Electron 验证。

验证边界：模拟 DAV 能验证协议请求与冲突，不代表所有服务商兼容。真实账户及签名证书未提供，交付明确列出未经过真实服务商和物理通知验证的部分。
