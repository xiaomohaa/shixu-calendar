# 1.3.0 月视图与缩放

用户反馈窗口/页面缩放期间卡死、日程文字错位，要求空间不足时改用彩色点或胶囊，文字加深，并按所附 macOS 日历截图更新界面。天气暂不加入。

## 布局与呈现

侧栏为浅灰背景，账户/日历在上，所选日期的农历黄历、日程摘要和迷你月历在下；保留原有账户、主题、托盘、自启和更新功能。主区用更大的深色年月标题、居中视图切换、搜索入口和右侧上一周期/今天/下一周期。正文和辅助文字提高对比度，保留 SF Pro 与苹方。月日格中的日期仍按先前要求居中，农历靠左，休班靠右；周末使用轻微中性底色。

月视图独立使用 CSS Grid，七列六行均为 minmax(0,1fr)，日程内容不能撑大日格。月网格只有一个 ResizeObserver，经动画帧合并后仅在显示档位变化时更新局部状态；不因缩放改变日期范围或访问数据库。周、日和列表继续使用 FullCalendar，关闭其 window resize 自动测量，由容器 ResizeObserver 合并后调用 updateSize，字体加载后也更新一次。

宽列、足够行高时展示按日历颜色着色的浅色胶囊，标题单行截断。列宽不足 116 CSS px 或行高不足 88 CSS px 时显示点阵，保留可点击的事件和 +N 入口。即使缩放很大，网格也保留 60px 最小行高，在日历内部滚动，避免文字堆叠到相邻日期。颜色混合使用 OKLab，避免近白背景色的色相把紫色胶囊变为橙色。

## 交互与数据

点击胶囊/圆点直接打开对应日程。+N 展开当天全部日程，长标题可换行、列表可滚动，可继续编辑和新建；Escape 和点击外部关闭，关闭后恢复焦点。日格键盘 Enter 选择并展开日程，Ctrl/Cmd+Enter 新建；双击空白/日期新建。跨日拖选可新建全天日程，拖动事件按源日格和目标日格的历日差平移，保持时长与浮动时间语义，服务层继续执行只读/冲突/重复实例保护。

按显示时区将定时事件投影到日格；全天 DTEND 为不包含的日期，定时事件午夜结束不计入次日。跨月事件在每个覆盖的日期都有胶囊/圆点，保留相同 ID 对应同一份日程。筛选不改写数据，所有显示来自实际缓存。

## 验证范围

先以 140 个本机 DAV 日程测量旧版，复现全部日程被 +N 折叠的现象，未在该次运行复现永久卡死。新版使用 321 个实际 DAV 事件验证长标题、跨月、圆点、胶囊、完整详情及真实拖动。覆盖 67%–200% 页面缩放、1000×680 到 1920×1080 窗口和连续 48 次尺寸变化，检查铺满、居中、越界、响应和缩放期间 IPC/网络读取数。测试不能代表所有显示器 DPI、系统版本与硬件均无任何卡顿。
