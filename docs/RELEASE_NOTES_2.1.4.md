# 时序日历 2.1.4

- 修复月历日程过早折叠的问题。旧算法仍按旧日期栏预留 40px，导致明明还有一行空间却显示“+N个”。现在测量真实日格、日期栏高度和底部边框，按 16px 日程、18px 行距计算容量。
- 去掉末行后多余空白与最多五行的限制。空间足够显示三项时全部显示，窗口放大后可显示更多行。
- 保留数量入口独占一行：只有真正放不下时才显示“+N个”；只够一行且同日两项时仍直接显示“+2个”，点击可查看全部。
- 验证最小窗口、紧凑窗口、常规窗口和高窗口之间连续缩放，所有日期保持可见，日程不被裁切，容量随实际空间恢复。
- 保留跨天胶囊、新建预览、独立日期选择、统一时区及全部日历同步功能。

已安装 Tauri 2.x 的用户，可在“设置 → 关于与更新”中检查更新，下载后选择“重启并安装”。也可下载 `Shixu-Setup-2.1.4-x64.exe` 覆盖安装，保留本地数据和账户设置。
