# 时序日历 1.1.0

Windows 10/11 x64 个人 CalDAV 客户端，简体中文界面，支持浅色与深色主题。

- 真实 CalDAV 服务发现、多账户多日历、双向同步、离线缓存及编辑队列。
- 月、周、日和列表视图，日程创建、编辑、删除及 ETag 冲突处理。
- 日期与农历居中显示，包含节气、传统节日和黄历宜忌详情。
- 中国大陆节假日“休”、调休补班“班”标识，已核对收录 2024–2026 年官方安排。
- 凭据使用 Windows DPAPI 加密，不向渲染进程返回密码。

## 下载

- `Shixu-Setup-1.1.0-x64.exe`：安装程序。
- `Shixu-Portable-1.1.0-x64.exe`：免安装启动器；数据仍保存在当前 Windows 用户的应用数据目录。
- `SHA256SUMS.txt`：两个程序的 SHA256 校验值。
